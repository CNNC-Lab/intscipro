# Day 8: *Machine Learning I*

## Overview
This day covers the foundations of machine learning for scientific data analysis. We explore supervised and unsupervised learning techniques, model evaluation strategies, and best practices for building robust ML pipelines:

1. **ML Fundamentals** - Supervised vs unsupervised learning, bias-variance tradeoff, data splitting
2. **Classification** - Logistic regression, decision trees, random forests, SVM, and evaluation metrics
3. **Regression** - Linear regression, regularization (Ridge, Lasso), and residual analysis
4. **Model Evaluation** - Cross-validation, learning curves, validation curves, and hyperparameter tuning
5. **Unsupervised Learning** - Clustering (K-Means, hierarchical, DBSCAN) and dimensionality reduction (PCA, t-SNE)
6. **Best Practices** - Pipelines, data leakage prevention, and ensemble methods

## Learning Objectives

By the end of this day, you will be able to:
- Understand the difference between supervised and unsupervised learning
- Implement classification models and evaluate them with appropriate metrics
- Build regression models with regularization to prevent overfitting
- Use cross-validation for robust model evaluation
- Interpret learning curves to diagnose model issues
- Apply clustering algorithms and evaluate cluster quality
- Use PCA and t-SNE for dimensionality reduction and visualization
- Build scikit-learn pipelines to prevent data leakage
- Perform hyperparameter tuning with Grid Search and Random Search
- Handle imbalanced datasets and high-dimensional data
- Build ensemble models for improved performance
