# Day 11: *Simulation and Modeling in Neuroscience*

## Overview
This day covers computational modeling and simulation techniques essential for neuroscience research. We explore differential equations, numerical methods, nonlinear dynamics, and multiscale modeling approaches:

1. **Differential Equations** - ODEs, SDEs, and PDEs for neural systems
2. **Numerical Methods** - Euler, Runge-Kutta, and implicit schemes
3. **Nonlinear Dynamics** - Phase space analysis, fixed points, and bifurcations
4. **Multiscale Modeling** - From molecules to whole-brain simulations

## Learning Objectives

By the end of this day, you will be able to:
- Understand the role of mathematical models in neuroscience research
- Formulate neural dynamics as systems of differential equations
- Implement numerical integration methods (Euler, RK2, RK4)
- Analyze dynamical systems using phase space and stability analysis
- Identify fixed points, limit cycles, and bifurcations
- Apply stochastic differential equations to model noise in neural systems
- Use the cable equation for spatially extended neurons
- Connect molecular, cellular, network, and systems-level models
- Choose appropriate model complexity for specific research questions
